cella 前端自测

零依赖的行为测试：在真实浏览器里 import 真实模块，派发真实事件，把断言结果写回页面。 用 headless 浏览器跑（无需 npm / 无需装 agent-browser）。五个套件共 191 项。

① grid.html —— 结果网格

61 项：固定布局与 colgroup、列宽拖拽 + 双击自适应、行高拖拽与垫片重算、三态排序、 勾选与全选、区块选区 + Ctrl+C TSV、点行号选整行 / Ctrl+A 全选、无 onSort 时本地排序，
回归：拖拽后的尾随 click 不触发排序/全选；setData 不冲掉手动列宽；
mousedown 选区不得重建 DOM（重建会打断浏览器 dblclick 计数 → 双击编辑失灵）。

② editor.html —— SQL 编辑器

17 项：高亮三类 token、Ctrl+/ 注释开关、Tab / Shift+Tab 整块缩进、括号引号自动配对与跳过、 成对删除、Enter 智能缩进、光标/滚动状态存取、Ctrl+↑↓ 历史回调、格式化。

③ panels.html —— 诊断/计划解析 + 耗时

27 项：四类诊断文本 → 结构化（缓冲池计数与命中率、锁表 X/S/等待者、等待图边与**环检测**、 事务表汇总与明细）、计划缩进树、渲染层 DOM 断言；耗时（毫秒格式化、空白折叠归一、速度分档、 记录倒序与序号、徽标三口径、耗时面板的历史对比表 + 条形 + 「相对上次同语句」变化率）。

④ layout.html —— 布局拖拽

40 项：偏好读写与夹逼、分隔条的位移/收尾回调；真实页面里拖侧边栏宽度、底部面板高度、 编辑器高度、网格行高与行号列宽，含上下限夹逼、双击复位与 localStorage 持久化，以及**连续拖拽/多步位移的基准回归**。

⑤ app.html —— 整体集成

46 项：在 iframe 里驱动真实页面 —— 两层树、数据工具条与每页行数、勾选批量删除按钮联动、 Ctrl+T/W 标签、切换保留光标、SQL 历史落库、右键菜单 6 项、诊断面板结构化与原始文本切换、 计划视图算子树 + 该语句耗时、断线横幅与加载态元素； 查询耗时显示（结果栏徽标与三口径 title、消息逐条耗时、状态栏入口、点徽标打开耗时面板、 数据工具条取数耗时）； Navicat 式暂存编辑全链路（编辑/新增/删除先暂存 → 左下角单事务提交 / 一键回退，用自建临时表隔离，不碰用户正在看的数据）。

怎么跑

先起服务（cella_web.exe --data ./mydb --port 8080），然后任一浏览器打开上面的页面即可； 结果直接打印在页面底部。

命令行（headless Edge，配合脚本化断言解析）：

msedge --headless=new --disable-gpu --virtual-time-budget=25000 \
       --user-data-dir=<临时目录> --dump-dom http://127.0.0.1:8080/_selftest/app.html

注意：--user-data-dir 用独立目录，避免并发实例互相占锁； 断言结果在输出 DOM 的 <pre id="out"> 里（每个 PASS/FAIL 一行）。
